# Ragdoll Rumble

A floppy ragdoll fighting game that runs in your browser, inspired by Roblox's Ragdoll Fight. Built with Claude.

**Play it:** open `index.html` in a browser, or turn on GitHub Pages for this repo and play at `https://charleskrebs.github.io/ragdoll-rumble/`.

## What's in it

- **30 fighters**, each with an ability, a ridiculous ultimate and a **domain expansion** (with 3D cutscenes and multi-way domain clashes)
- **Story Mode** with cutscenes, 6 chapters and a final boss
- **Tutorial**, 1 vs CPU, 2 players on one keyboard, and Brawl (you vs 3 CPUs)
- **Anime Awakenings** when you're almost out of HP
- **Ball VS Ball** minigame: collect 77 balls across Common, Rare, Epic, Legendary, Mythic, Secret and Ascended tiers, open crates, build your own ball with up to 3 powers in the Ball Maker, and redeem gift codes
- **Accounts** with passwords and recovery codes

## Controls

| | Player 1 | Player 2 |
|---|---|---|
| Move | A / D | ← / → |
| Jump | W | ↑ |
| Punch | F | . |
| Kick | G | / |
| Ability | E | , |
| Ultimate | Q | M |
| Domain | R | N |

Esc opens the menu, M toggles sound.

## Notes

- Saves (accounts, coins, balls) are stored in your browser. Online play and cloud saves only work in the claude.ai version of the game.
- Everything is in a single HTML file with no build step.

Made with Claude.
